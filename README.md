# 📡 مراقب خطوط شبكة الهيثم

يفحص خطوط سوبرنت ADSL كل ساعة تلقائياً (مع قراءة الكابتشا آلياً)، ويعرض لوحة محمية بكلمة سر، ويرسل تقريراً يومياً على تيليجرام الساعة 11:55 مساءً.

## ما الذي يفعله
- **كل ساعة:** يدخل كل خط، يقرأ الرصيد والباقة والحالة وتاريخ الانتهاء، ويحدّث اللوحة.
- **اللوحة:** الإجمالي المتبقي في الأعلى، بطاقة لكل خط، **أحمر وامض** لأي خط تحت 100 جيجا، رسم بياني للاستهلاك اليومي، وسجل الأيام.
- **تيليجرام فوراً:** عند نزول خط تحت 100 جيجا، وعند شحن خط، وإذا فشل الفحص 3 مرات متتالية.
- **تيليجرام 11:55 مساءً:** استهلاك كل خط اليوم + المتبقي + المجموع.
- كل البيانات **مشفّرة** (AES-256) ولا تُقرأ إلا بكلمة سر اللوحة.

---

## خطوات التركيب (مرة واحدة)

### 1) إنشاء المستودع
1. في GitHub اضغط **New repository**، الاسم مثلاً `alhaitham-monitor`، واختر **Public** (مطلوب لـ GitHub Pages المجاني، والبيانات مشفّرة).
2. اضغط **uploading an existing file** وارفع كل ملفات هذا المجلد (كلها في الصفحة الرئيسية).

> مجلد `.github` مخفي في بعض الأجهزة. إذا لم يُرفع، أنشئ ملفاً جديداً باسم `.github/workflows/monitor.yml` والصق محتواه.

### 2) إضافة الأسرار
**Settings → Secrets and variables → Actions → New repository secret** وأضف 4 أسرار:

| الاسم | القيمة |
|---|---|
| `LINES_JSON` | قائمة الخطوط (انظر بالأسفل) |
| `DASH_PASSWORD` | كلمة سر تختارها لفتح اللوحة |
| `TELEGRAM_TOKEN` | توكن البوت من @BotFather |
| `TELEGRAM_CHAT_ID` | رقم محادثتك (أرسل أي رسالة للبوت ثم افتح `https://api.telegram.org/bot<TOKEN>/getUpdates` وخذ رقم `chat.id`) |

قيمة `LINES_JSON`:
```json
[
  {"name": "الخط الأول",  "user": "214314",  "pass": "كلمة_السر"},
  {"name": "الخط الثاني", "user": "1468379", "pass": "كلمة_السر"},
  {"name": "الخط الثالث", "user": "1207955", "pass": "كلمة_السر"}
]
```

### 3) تفعيل اللوحة
**Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` والمجلد `/ (root)` → Save.
بعد دقيقة يظهر الرابط: `https://اسمك.github.io/alhaitham-monitor/`

### 4) أول تشغيل
**Actions** → **مراقبة خطوط شبكة الهيثم** → **Run workflow** → `check`.
بعد أن ينجح، افتح رابط اللوحة وأدخل `DASH_PASSWORD`.
لتجربة التقرير: شغّله مرة ثانية واكتب `report`.

### 5) تثبيتها كتطبيق على الجوال
افتح الرابط في **كروم** → القائمة ⋮ → **إضافة إلى الشاشة الرئيسية**.

---

## إضافة خط جديد لاحقاً
عدّل السر `LINES_JSON` وأضف سطراً جديداً:
```json
{"name": "الخط الرابع", "user": "رقم_الخط", "pass": "كلمة_السر"}
```
لا تحتاج تعديل أي كود. ولحذف خط احذف سطره.

## تغيير حد التحذير
**Settings → Secrets and variables → Actions → Variables** → أضف `LOW_LIMIT_GB` بالقيمة التي تريدها (مثلاً `150`).

---

## إذا فشل الفحص
افتح **Actions** وآخر تشغيل وانظر السجل:
- **`فشل الدخول بعد 10 محاولات`**: قراءة الكابتشا لم تنجح، أرسل لي السجل.
- **`Connection timed out` / `Connection refused`**: موقع يمن نت يحجب خوادم GitHub (خارج اليمن). الحل: تشغيل نفس السكربت على جهاز داخل اليمن (كمبيوتر أو جوال أندرويد بـ Termux) يرفع النتائج للمستودع، واللوحة تبقى كما هي.
- **`بيانات الدخول خاطئة`**: راجع كلمة السر في `LINES_JSON`.

ملاحظة: جدولة GitHub قد تتأخر أحياناً 5–20 دقيقة عن الوقت المحدد، وهذا طبيعي.
